# 🛒 Trois Caïmans Distribution

Site e-commerce développé pour présenter des produits et faciliter les commandes via WhatsApp.

## 🎯 Objectif

Créer une vitrine en ligne simple et accessible permettant aux clients de découvrir les produits et de passer commande directement via WhatsApp.

## ✨ Fonctionnalités

* 🛍️ Présentation des produits
* 📱 Commande via WhatsApp
* 📸 Intégration des images et médias
* 📱 Interface adaptée à différents écrans
* 🎨 Design personnalisé
